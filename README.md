# bionics-structure-function

一个开源的 CodeBuddy / WorkBuddy Skill：在「动物结构 ↔ 功能 ↔ 应用」之间做双向分析，输出固定六节的 Markdown 报告。

面向仿生学课程作业、选题调研、方案论证。核心设计原则是**宁可说不知道，也不编数据**。

## 它做什么

支持两个方向：

### A 结构驱动 —— 从动物结构出发

给一句「鲨鱼皮为什么能减阻」，它输出：

1. 一句话结论
2. 结构描述（尺度 / 材料 / 形貌三层）
3. 功能机制（L4 物理机制 + L5 生物学功能）
4. 结构—功能对应表（每条标注证据强度）
5. 仿生启发与实际应用
   - 5.1 实际生活应用（日常能买到、能接触到的产品与场景，至少 1 条）
   - 5.2 工程与前沿应用（科研与工业映射）
6. 信息缺口与置信度（假设项、未查证数据、待查证文献）

### B 需求驱动 —— 从生产/生活需求反查动物结构

给一句「管道内壁残留多、清洗耗水，有什么动物结构可以借鉴」，它输出：

1. 一句话结论（推荐借鉴的结构 + 核心机制）
2. 需求拆解（工况参数表 + 功能抽象：一个功能动词 + 一个可测量的物理目标）
3. 候选动物结构表（至少 3 个，逐条标注匹配度与主要风险）
4. 首选结构详解（五层拆解 + 为什么排第一 + 生境差异）
5. 落地应用与迁移风险
   - 5.1 实际生活应用（至少 1 条）
   - 5.2 目标需求的实现路径（含可执行的验证建议）
6. 信息缺口与置信度（另含检索边界：动物界以外有更成熟方案时会提示，但不展开）

## 它不做什么

只处理**动物结构与功能的对应关系**（含从需求反查动物结构）。以下一律拒答：

- 植物 / 微生物 / 生态系统的仿生
- 纯动物分类、饲养、解剖背诵、习性科普
- 设备选型、工艺计算、强度校核、成本报价、法规判定（B 模式只给生物候选、机制与验证建议）
- 纯工程设计（无生物侧输入）
- 医学、药物、保健品、人体养生
- 其他一切领域

## 四条硬规则

1. **边界** — 只处理动物结构—功能对应问题（含从需求反查动物结构），超出范围直接说不在能力范围。
2. **固定格式** — 先判方向再选模板：结构驱动用 `assets/report-template-a-structure-driven.md`，需求驱动用 `assets/report-template-b-need-driven.md`；选定后六个一级标题不增不减、不改标题文字。
3. **不脑补** — A 模式缺物种/结构/功能方向/应用领域任一项即提问；B 模式缺需求描述/介质与工况/现有方案痛点/约束任一项即提问。一次最多问 3 个。
4. **不编造** — 数值无来源写「未查证」，无法核实写「待查证」，推论前加〔推断〕标记。

## 安装

**用户级**（所有项目可用）：

```bash
cp -r bionics-structure-function ~/.codebuddy/skills/
```

**项目级**（随仓库共享）：

```bash
mkdir -p .codebuddy/skills && cp -r bionics-structure-function .codebuddy/skills/
```

安装后直接提问即可触发，会自动判断走哪个模式。

**A 结构驱动**（给出动物结构）：

- 「壁虎脚掌的刚毛是怎么实现附着的？我想用在爬壁机器人上。」
- 「猫头鹰飞行静音的结构原理是什么，对风机叶片降噪有什么启发？」
- 「贝壳珍珠层的增韧机制，能用到陶瓷材料上吗？」
- 「翠鸟入水不溅水花，这个结构在日常生活里有什么实际用处？」（不给应用领域也能出报告，5.1 会自行展开生活场景）

**B 需求驱动**（给出需求，反查结构）：

- 「食品厂管道输送高黏度酱料，内壁残留多、CIP 清洗耗水，有什么动物结构可以借鉴？」
- 「车间风机噪声大，有没有能降噪的动物结构可以参考？介质是空气，常温常压。」
- 「脆性陶瓷件容易崩裂，想提高抗冲击性，自然界有什么结构思路？」

## 输入建议

一次给全必填项，可以跳过追问直接出报告。

**A 模式：**

| 字段 | 必填 | 示例 |
|---|---|---|
| 动物物种 | 是 | 壁虎（*Gekko gecko*） |
| 目标结构 | 是 | 脚掌刚毛（seta）阵列 |
| 功能方向 | 是 | 附着 / 可控脱附 |
| 应用领域 | 是 | 爬壁机器人末端 |

**B 模式：**

| 字段 | 必填 | 示例 |
|---|---|---|
| 需求描述 | 是 | 管道内壁残留多，清洗耗水耗时长 |
| 介质与工况 | 是 | 高黏度水性酱料，常温，间歇运行 |
| 现有方案与痛点 | 是 | 不锈钢裸管 + CIP 碱洗，耗水多 |
| 约束 | 是 | 食品接触合规，耐碱洗，不能脱落 |
| 周期与寿命 | 否 | 每批次清洗一次，期望半年以上 |

## 修改与扩展

- 增删功能族、补充术语、调整生活应用落点表或需求→结构映射表：改 `references/analysis-framework.md`
- 调整提问方式、话术、B 模式必填项、生活应用标注要求：改 `references/intake-checklist.md`
- 改输出章节结构：同步改 `assets/report-template-a-structure-driven.md`（或 B 版）与 `SKILL.md` 的「固定输出格式」一节，两处必须一致
- 新增示例：沿用 `examples/` 下现有文件的写法，并在开头注明该文件演示的重点
